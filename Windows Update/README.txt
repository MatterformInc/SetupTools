================================================================================
  WINDOWS UPDATE — Reduce interruptions and surprise restarts
  For activations, Unreal, TouchDesigner, and long-running installs
================================================================================

Windows does not expose full update control via script on all editions.
Use Settings (run open-update-settings.bat) and this checklist.

ACTIVE HOURS
------------
• Set when you use the PC so Windows won’t restart during that time.
• Settings > Windows Update > Advanced options > Active hours
• Set “Start” and “End” to cover your work/render window (e.g. 6 AM–11 PM).

PAUSE UPDATES
-------------
• You can pause quality/feature updates for a limited time (e.g. up to 5 weeks).
• Settings > Windows Update > Pause updates / Pause for 1 week (or max).
• Use before critical installs or long renders; resume and install when safe.

RESTART OPTIONS
---------------
• Under Advanced options: turn off “Restart this device as soon as possible…”
• Optional: set “Schedule the restart” to a time you choose after updates are ready.

OTHER
-----
• Delivery Optimization (uploading to other PCs) is turned off by
  Stability\stability-settings.bat if you ran it as Administrator.
• On managed PCs, Group Policy may override these; check with IT.
